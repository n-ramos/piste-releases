# Piste — téléchargements

Ce dépôt distribue uniquement les installateurs signés, les archives de mise à jour et le manifeste `latest.json` de l’application Piste. Le code source du projet reste dans un dépôt privé.

[Ouvrir la dernière version](https://github.com/n-ramos/piste-releases/releases/latest) pour télécharger l’installateur Windows, macOS ou Linux. Sous Windows, lancez le fichier `*-setup.exe` par double-clic ; aucune commande n’est nécessaire. FFmpeg et FFprobe sont inclus dans l’application.

La signature cryptographique des mises à jour est vérifiée par Piste avant installation. Elle ne remplace pas la signature de réputation Windows Authenticode ni la notarisation macOS ; ces deux attestations ne sont pas encore fournies.
